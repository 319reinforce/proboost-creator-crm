## Design Context

### Users
ProBoost creator operations users manage invite-code imports, send-mail batches, inbox follow-up classification, and audit logs. They work in a local operator console where speed matters, but accidental real sending, stale batch state, and unclear failures are costly.

### Brand Personality
Controlled, premium, decisive. The interface should feel like a modern operations desk: calm enough for repeated daily work, polished enough to inspire confidence, and direct about risk.

### Aesthetic Direction
Use a refined light-first console with dark-mode support, tinted neutrals, purposeful accent colors, dense but readable layouts, and data-led dashboards. Avoid legacy Element UI blue, flat gray pages, decorative gradients without information value, and marketing-page composition.

### Design Principles
- Make status and risk instantly scannable before asking the user to act.
- Use depth, color, and motion to explain state changes, not as decoration.
- Preserve operator context during live updates; never make SSE refreshes feel like a page reset.
- Keep forms compact and ergonomic for repeated batch work.
- Support reduced motion and dark color preference without degrading the workflow.
